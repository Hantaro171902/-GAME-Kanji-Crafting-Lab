# MindForge Academy

A 2D educational puzzle game built with **Flutter** + **Flame** — playable on
**Android** and **Web** from one codebase.

Players solve brain-training puzzles (logic, math, memory, pattern, reflex) to
earn Element Shards, then combine Elements in the Alchemy Lab to discover new
ones and unlock further chapters.

## Getting started

```bash
flutter pub get
flutter run -d chrome        # web
flutter run -d <android-device>   # android
```

> The `android/` and `web/` platform folders are generated by Flutter. If they
> are missing, run `flutter create --platforms=android,web --org com.mindforge .`

## Project layout

```
lib/
├── main.dart                 # bootstrap: Hive init, repository, runApp
├── app.dart                  # ProviderScope + MaterialApp.router
├── core/
│   ├── constants/            # game-wide constants
│   ├── theme/                # Material 3 theme
│   ├── router/               # go_router routes
│   └── storage/              # Hive-backed local persistence
├── models/                   # PlayerProfile, LevelData, ElementData
├── data/
│   ├── level_catalog.dart    # data-driven level definitions
│   ├── element_catalog.dart  # 18-element crafting catalog
│   └── repositories/         # progress repo + remote sync stub
├── gameplay/
│   ├── mindforge_game.dart   # Flame game (mascot, confetti)
│   ├── puzzles/              # pure-Dart puzzle controllers (5 types)
│   └── crafting/             # element combination logic
├── screens/                  # splash, home, chapter map, puzzle, lab, ...
└── widgets/                  # shared UI (HUD, star rating, tiles)
```

## Puzzle types

| Mechanic | Controller | Skill |
|---|---|---|
| `quick_arithmetic` | `MathPuzzleController` | Arithmetic fluency |
| `sequence_memory` | `MemoryPuzzleController` | Working memory |
| `next_in_sequence` | `PatternPuzzleController` | Pattern recognition |
| `sudoku_lite` | `LogicPuzzleController` | Deductive reasoning |
| `pick_the_color` | `ReflexPuzzleController` | Processing speed |

Levels are data-driven (`LevelData` JSON shape) — new levels need no code.

## Art assets

Pictographic radical art (SVG + 2x PNG) lives in `assets/images/radicals/` —
characters like 木 (tree), 日 (sun), 山 (mountain) drawn so the glyph stays
readable while evoking the real object. Preview gallery:
`docs/radicals-preview.html`.

## Backend (optional)

Offline-first by default. Sync to Firebase Firestore (NoSQL, free tier) via
`RemoteSyncService` in `lib/data/repositories/`. See `docs/ARCHITECTURE.md`.

## Testing

```bash
flutter test
```

Pure-Dart puzzle controllers are unit-testable without a device
(`test/puzzles/`).
